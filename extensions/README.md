# 拓展与物理分组

每个题库分组使用自己的配套拓展分组，均只支持一层。普通题库以 `{path}` 引用本组拓展，路径相对产品数据根目录并使用 `/`。不同分组中的拓展是独立副本；同组内可以共用。界面名称取文件夹名，旧 ID、版本保留为元数据。

`基础题型/` 内单选、多选、判断、简答四种制作参考拓展均为 2.0.0；答题区为 1.0.0；政治、408使用的简答副本为2.0.1，保留其待评分行为，不与2.0.0合并。

| 题型 | ID | 目录 | 评分 |
| --- | --- | --- | --- |
| 单选 | quizforge.single-choice | [单选题](基础题型/单选题) | 选对得满分 |
| 简答 | quizforge.short-answer | [简答题](基础题型/简答题) | 人工评分或 AI 评分 |
| 多选 | quizforge.multiple-choice | [多选题](基础题型/多选题) | 全部选对得满分，漏选或错选不得分 |
| 判断 | quizforge.true-false | [判断题](基础题型/判断题) | 判断正确得满分 |
| 答题区 | quizforge.answer-area | [答题区](基础题型/答题区) | 同框文字、手写、拍照／图片；提交后待人工或 AI 评分 |

简答支持单问或共享材料下的多个小问；提交后默认 0 分，人工评分以 0.5 分为步长自动保存。AI 评分使用应用配置，支持按小问评分；是否提交后自动评分由应用的自动评分设置控制。空白作答计 0 分。

每个拓展含自己的同题型示例。混合展示库位于 [基础题型展示](../question-banks/基础题型/基础题型展示)，共 11 题、总分 43 分。编辑、白板、历史及考试全部开启。

引用示例：

```json
{"extension":{"path":"extensions/基础题型/单选题"}}
```

每个拓展的 `examples/bank.json` 精确自绑定自身副本。交付使用宿主导出的格式3 `.qbank`，同时携带 `question-banks/<组名>/<题库名>/` 和 `extensions/<组名>/<拓展名>/`；不包含作答、历史、设置或内部保存身份。每次导入均为新副本，最终题库与拓展分组名称分别由宿主避让重名。

产品不再区分开发版和正式版。后续修改先备份，保持答案结构及题目、小题 ID 兼容。导入导出与迁移约定见 [LIBRARY_PACKAGES.md](../core/docs/reference/LIBRARY_PACKAGES.md)。公开仓库和预览包只附带上述五种基础拓展，其他题型可另外制作或随题库包导入。
