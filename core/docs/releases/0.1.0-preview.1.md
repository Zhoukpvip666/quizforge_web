# QuizForge 0.1.0-preview.1

第一份 Windows 预览版，面向体验与反馈，不标记为稳定版。

## 下载与启动

下载 `QuizForge-0.1.0-preview.1-win-x64.zip`，将整个文件夹解压到可写目录，双击 `QuizForge.exe`。支持 Windows 10/11 x64，托盘使用系统 .NET Framework 4.8。包内包含 Node.js 24，用户无需安装 Node.js 或 Java。

- 服务就绪后自动打开应用网页；启动过程不显示命令窗口。
- 左键单击托盘打开网页；右键查看状态、地址与运行时长，或退出 QuizForge。
- 关闭浏览器后服务继续运行。退出托盘等待服务处理完已收到的保存请求，再关闭后台服务；退出前请确认页面输入已保存。
- 重复启动复用同一托盘和服务。已有脚本服务或端口占用时提示先关闭旧服务，不自动接管其他进程。

首次附带基础题型展示库（10 题）和单选、多选、判断、富文本简答四种基础拓展。其他题库可通过应用内“获取题库”访问题库广场，下载 `.qbank` 后在应用主机导入。

## 功能范围

题库与拓展管理、分组导入导出、练习及统一评分、题目大纲、富文本与图片、白板草稿、考试和只读历史、人工及 AI 评分、本机/局域网/公网 IPv6 连接。应用直连使用 HTTP；HTTPS 需要自行配置外部反向代理。

题库及拓展通过 UUID 和实际路径保持身份；不区分开发版与正式版。图片随题库包保存，新导入含图题库无需先打开即可导出。完整功能与接口见 [功能清单](../../../FEATURES.md)和[开发者文档](../README.md)。

## 已知问题

以下测试报告中的问题仍待当前版本复测或修复：

1. 窄屏首次进入草稿，可能出现画布过小、笔迹变成单点或灰块。
2. 相同内容的服务重启后，旧页面重试保存可能误报题目内容已更新；退出前应先保存。
3. 某些旧简答拓展返回待评分时，大纲可能误显示为错误。
4. 在分值汇总页改名后，题名及保存提示可能没有即时刷新。
5. 同身份、同版本但内容不同的拓展并存时，旧格式题库包导出可能被重复 ID 检查拒绝。

自动测试、隔离 EXE 及解压包运行验证不能替代原生托盘鼠标点击、默认浏览器、真实手机/触控笔/摄像头、公网和真实 AI 服务的人工验收。遇到问题请提供版本、系统、复现步骤及脱敏截图。

## 数据与源码

发布包和公开仓库只附带基础内容，不含维护者的题库、个人作答、草稿、历史、设置、API Key、人工测试表或内部开发日志。公开源码包含自动测试、兼容夹具、开发文档、制作技能和构建脚本；运行依赖与生成的二进制通过发布附件提供。
