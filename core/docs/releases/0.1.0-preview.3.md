# QuizForge 0.1.0-preview.3

第三份 Windows 预览版，面向体验与反馈，不标记为稳定版。本版主要增加手机和平板上的使用方式（安装为应用、HTTPS、Tailscale）、外观主题，以及更简洁的网络设置；题库格式不变，可直接使用原有题库和作答数据。

## 下载与启动

下载 `QuizForge-0.1.0-preview.3-win-x64.zip`，将整个文件夹解压到可写目录，双击 `QuizForge.exe`。支持 Windows 10/11 x64，托盘使用系统 .NET Framework 4.8。包内包含 Node.js 24，用户无需安装 Node.js 或 Java。

从旧版升级：先在托盘中退出旧版，再把旧目录中的 `question-banks/`、`extensions/` 及 `.state/` 复制到新目录。保留旧目录作为备份，确认新版正常后再删除。网络连接、外观等设置会一并保留。

## 本版改动

### 手机与平板

- **安装为应用**：用 HTTPS 地址打开时，可以在 Chrome、Edge 中“安装应用”，从桌面图标打开时没有地址栏。
- **Tailscale**：电脑和手机登录同一个 Tailscale 账号后，网络设置里会直接显示 `https://电脑名.xxx.ts.net/` 这样的地址（需在电脑上用 `tailscale serve` 把 HTTPS 转发到连接端口），证书由 Tailscale 自动签发，手机无需安装证书，电脑 IP 变化也不影响。推荐优先使用这种方式。
- **局域网 HTTPS（备用）**：不用 Tailscale 时，可在局域网内开启 QuizForge 自带的 HTTPS，每台手机需要安装一次本机根证书。

### 网络设置

- 改为简洁的连接列表：局域网、公网 IPv6、公网 IPv4／自定义地址、Tailscale 分行显示能直接在浏览器打开的地址，每行可一键复制，右上角可刷新。
- 开启“外网连接”后，检测到的公网 IPv6 和 Tailscale 地址直接可用，不再需要先填写公网地址并保存；自定义地址改为选填，供端口映射或反向代理使用。

### 外观

- 设置 → 外观可选择六套主题：默认、晨雾、纸张、护眼米黄、护眼豆绿和图片；“图片”主题可换成本机图片（只保存在这台设备的浏览器中）并调节遮罩。
- “面板透明度”可调节题库列表、目录大纲、顶栏和底栏透出背景的程度，每个主题分别记住；加载题库和题目时显示主题背景，不再是白屏。
- 单选、多选、判断、简答四种基础题卡跟随主题配色，并随面板透明度变得半透明；草稿模式和手机宽度下保持不透明。

### 草稿与白板

- 切题后题卡位置保持一致，平移和缩放按题记住。
- 白板工具栏重做：手形工具合并操作与移动，画笔与颜色合并；整条工具栏可拖动并停靠在四边或四角，收起时阴影不再拉长。

### 修复

- 重新加载首页时偶尔出现空白的 400 页面。
- 从源码启动时依赖不全，现在会说明缺少哪些包以及修复命令，而不是只提示“服务已停止”。
- 草稿模式截图在新的主题题卡上报错（unsupported color function "color"）：截图前会把新的 CSS 颜色写法转换成截图组件能识别的格式。本版首次上传的安装包有这个问题，已替换为修复后的安装包。

## 行为变化

- **拓展接口升级到 API 1.4**：新增只读的外观接口（`QF.ui.appearance`），拓展可以读取主题和透明度。本版附带的四个基础拓展声明需要 API 1.4，不能再装回 0.1.0-preview.2 及更早版本；旧拓展和已有题库不受影响。
- 开启“外网连接”后，除自定义地址外，本机检测到的公网 IPv6 地址和 Tailscale 地址也会被接受，所有地址仍需连接密码。不需要外网访问时请保持该开关关闭。
- QuizForge 只读取 Tailscale 的状态（`tailscale status`、`tailscale serve status`），不会修改 Tailscale 的任何设置。
- 新增 MIT 许可证。

## 已知问题

以下问题在之前版本中记录，本版尚未确认修复：

1. 窄屏首次进入草稿，可能出现画布过小、笔迹变成单点或灰块。
2. 相同内容的服务重启后，旧页面重试保存可能误报题目内容已更新；退出前应先保存。
3. 某些旧简答拓展返回待评分时，大纲可能误显示为错误。
4. 在分值汇总页改名后，题名及保存提示可能没有即时刷新。
5. 同身份、同版本但内容不同的拓展并存时，旧格式题库包导出可能被重复 ID 检查拒绝。

本版新增、尚未在真机上验收的部分：手机经 Tailscale 访问与安装应用、手机安装局域网 HTTPS 根证书、平板上白板工具栏的拖动手感与触控笔，以及题卡主题在多选、判断、简答和编辑模式下的效果。电脑上运行 Clash 等代理软件时，请把 `*.ts.net` 设为直连，并避免开启 TUN 模式，否则 Tailscale 可能无法直连或速度很慢。

自动测试、隔离 EXE 及解压包运行验证不能替代原生托盘鼠标点击、默认浏览器、真实手机/触控笔/摄像头、公网和真实 AI 服务的人工验收。遇到问题请提供版本、系统、复现步骤及脱敏截图。

## 数据与源码

发布包和公开仓库只附带基础内容，不含维护者的题库、个人作答、草稿、历史、设置、API Key、人工测试表或内部开发日志。公开源码包含自动测试、兼容夹具、开发文档、制作技能和构建脚本；运行依赖与生成的二进制通过发布附件提供。
