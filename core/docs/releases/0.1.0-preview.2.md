# QuizForge 0.1.0-preview.2

第二份 Windows 预览版，面向体验与反馈，不标记为稳定版。本版集中改善切题、切换题库和评分的响应速度；功能范围、数据格式和拓展接口与 0.1.0-preview.1 相同，可直接使用原有题库和作答数据。

## 下载与启动

下载 `QuizForge-0.1.0-preview.2-win-x64.zip`，将整个文件夹解压到可写目录，双击 `QuizForge.exe`。支持 Windows 10/11 x64，托盘使用系统 .NET Framework 4.8。包内包含 Node.js 24，用户无需安装 Node.js 或 Java。

从 0.1.0-preview.1 升级：先在托盘中退出旧版，再把旧目录中的 `question-banks/`、`extensions/` 及 `.state/` 复制到新目录。保留旧目录作为备份，确认新版正常后再删除。

## 本版改动

- **切题更快**：空闲时预取前后题目及其题型页面；连续快速点击或按键直接跳到目标题，不再逐题加载。焦点不在输入框、题卡、对话框或草稿中时，可按 ← / → 切题。
- **切换题库更快**：读取已打开的题库只复核该题库文件及其关联拓展，不再每次扫描全部题库。切回已打开题库由约 4–5 秒降到 1 秒以内。
- **评分更快**：同一拓展复用常驻规则进程，单次评分或答案校验由约 1 秒降到几十毫秒；“完成练习”（8 道题）由约 12 秒降到约 3 秒。启动后的后台校验不会挡住保存和读题。
- **完成练习不再误报**：评分时间较长时，“完成练习”和“开始新一轮”最长等待 135 秒，不再在服务端已完成时提示“完成练习未保存”。

## 行为变化

- 在应用外新增同 ID 题库，或安装同一拓展的更高版本，会在下一次完整扫描（打开目录列表、刷新、导入）后生效。在应用外修改已打开题库本身的文件，下一次读取仍会立即生效。
- 同一拓展的规则请求共用常驻 Node 进程，每次请求仍使用新的 VM 环境；不同拓展之间仍然隔离。规则执行环境与以前一样，不能替代完整的恶意代码隔离，请只安装可信拓展。
- 常驻规则进程空闲 60 秒后退出，通常同时存在 1–4 个，每个约 30–40MB。
- 焦点在页面按钮或题目大纲上时，← / → 会切换题目。

## 已知问题

0.1.0-preview.1 中记录的以下问题本版尚未修复：

1. 窄屏首次进入草稿，可能出现画布过小、笔迹变成单点或灰块。
2. 相同内容的服务重启后，旧页面重试保存可能误报题目内容已更新；退出前应先保存。
3. 某些旧简答拓展返回待评分时，大纲可能误显示为错误。
4. 在分值汇总页改名后，题名及保存提示可能没有即时刷新。
5. 同身份、同版本但内容不同的拓展并存时，旧格式题库包导出可能被重复 ID 检查拒绝。

另外，首次打开某本题库仍需完整校验，可能要数秒；单题保存整体仍需约 0.5 秒。

自动测试、隔离 EXE 及解压包运行验证不能替代原生托盘鼠标点击、默认浏览器、真实手机/触控笔/摄像头、公网和真实 AI 服务的人工验收。遇到问题请提供版本、系统、复现步骤及脱敏截图。

## 数据与源码

发布包和公开仓库只附带基础内容，不含维护者的题库、个人作答、草稿、历史、设置、API Key、人工测试表或内部开发日志。公开源码包含自动测试、兼容夹具、开发文档、制作技能和构建脚本；运行依赖与生成的二进制通过发布附件提供。
