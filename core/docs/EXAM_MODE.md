# 考试模式

题库根 `features.exam` 控制考试入口，与编辑、白板、历史一样，未声明时默认开启；只有布尔值 `false` 才关闭。省略整个 `features`、使用空对象或仅声明其他功能均不关闭考试。需要关闭时在题库文件写 `"features":{"exam":false}`；列表编辑仅修改名称和分组，不提供功能开关。普通练习继续保留。拓展不声明是否考试，宿主决定能力、计时与交卷。开始前选择 1–1440 分钟或不限时。限时到点自动交卷，后端锁定答案；不限时显示已用时间，手动交卷。关闭页面不暂停限时考试。

考试是独立集合 `kind:"exam"`，与练习的答案、白板、评分及历史分开。开始时冻结题目、顺序、大纲及拓展文件；后续修改原题库或拓展不影响本次考试。历史开启时保存在 `.state/exams/<id>/` 和独立状态文件，服务重启后恢复截止时间与已保存的答案；历史关闭时个人作答、图片、AI 任务和结果只留原页面会话内存，不保存考试元数据或历史。

关闭历史的考试要求 `X-QuizForge-Practice-Session` 为当前页面生成的 UUID；缺少时返回 `409 PRACTICE_SESSION_REQUIRED`，其他页面不能读取、保存、删除或重放该考试。服务最多同时保留 32 次临时考试，按冻结内容、状态、图片及 AI 任务的编码大小计入 256 MiB 预算，并为一次写入预留 32 MiB。达到容量时拒绝新增或写入，保留已有作答。页面连续 30 分钟没有访问后，后台检查及后续请求会释放其临时考试；同一页面的正常访问会更新闲置时间。编码预算用于约束保留数据量，并不代表 Java 堆内存的精确上限。

临时考试仍会在独立 UUID 目录中复制供规则进程读取的拓展包。删除、过期、启动失败或服务关闭时回收这份复制；删除重放元数据最多保留 256 条。清理只处理经过路径校验的临时 `packages` 目录，检测到持久记录、额外文件、符号链接或越界路径时保留目录并记录提示。

已完成考试与普通练习统一在原题库的“历史记录”中查看和删除，列表及只读页面标注“考试”，可以切换查看保存的草稿、使用大纲及左右箭头浏览。考试入口只展示未完成考试和待处理评分，不展示已完成成绩。既有考试记录直接读取原快照，无须迁移或修改题库、拓展；删除历史不会改变普通练习进度，也不会重新生成已删除的记录。

考试设置弹窗中，每条未完成考试或待处理评分旁有独立的删除按钮，删除前需在页面确认。删除先持久保存 `status:"deleted"` 与 `deletedAt`，再移除可用集合缓存；服务重启后不会恢复该考试、继续倒计时、交卷或重新评分。冻结文件和独立状态保留用于恢复，不在此操作中清理磁盘；在途 AI 响应通过集合失效校验，不再采用。历史关闭的临时考试还会关闭其评分服务并清空个人作答、图片内存。保存取消标记失败时仍保留原考试，可重试。已完成考试须从历史记录删除。

## 页面与规则

考试中已保存答案的普通题在大纲显示紫色“已作答”；小题由原 `getScore(data,state).outlineStates` 按小题 ID 返回 `draft`（已填写待提交）或 `unanswered`（未填写）。宿主不根据父题有答案推断全部小题已作答，未提交也不显示对错或计分。交卷评分后改用 correct/incorrect，状态约定见 [小题大纲](SUBQUESTION_OUTLINE.md)。

现有规则 `project/validateAnswer/grade/getScore/review/prepareAiGrading` 复用，无须新增考试判分规则。页面收到 `mode:"exam"`、`exam:{id,status,deadline}`。考试中 `canSave:true/canSubmit:false`，保存与提交必须独立；`onFlush` 排空本地保存队列。按钮标记 `data-qf-action="submit"` / `"retry"` 后宿主统一隐藏；其他旧拓展须自行按能力隐藏。宿主同时拒绝单题提交、重做、编辑和考中评分，不能只靠隐藏按钮。

交卷先保存当前页面，再持久锁定整卷答案，再逐题提交已保存的非 null 答案；无答案的题目保持未作答并计 0 分。自动交卷使用服务器截止时间，无法保存截止后的输入。评分异常保留已保存答案并允许“重试评分”，不会重新开放作答。自动 AI 按现有 `automatic:true` 计划处理整题或小题；失败时保持“评分失败，待处理”，可以重试或调用既有 review 人工评分。全部评分处理完再完成考试记录。这里的 exam 是个人考试练习功能，不构成反作弊隔离；同一应用仍可另开普通练习查看材料。

宿主兼容当前内置单选 1.0.0、简答 1.3.0 的已知提交／重做按钮，无须修改其正式包；其他旧拓展依照 `canSubmit` 和上述按钮标记适配。考试快照与可变的计时／评分元数据分开保存，已完成考试按需加载，持久考试的题目缓存最多 8 份。

## 宿主 HTTP

- `GET /api/collections/{bank|development-bank}/{id}/exams`：列出该题库的考试，包含进行中、评分中及已完成记录。
- `GET .../history`：既有历史接口合并普通练习与已完成考试，按更新时间倒序；考试条目携带 `mode:"exam"`、`examId`，公开记录 ID 为 `exam-{examId}`，未完成考试不加入历史列表。
- `GET/DELETE .../history/{recordId}`：考试使用同一历史读取／删除接口，读取当次冻结的题目、页面、答案、分数和白板。考试条目只属于原 `bankKind/bankId`；删除后不再列出，重启也不会恢复。历史关闭时仍不可读取／保存。
- `POST .../exams`：`{requestId,durationMinutes:60}`，或 `durationMinutes:null`；同请求重放不重复创建。
- `GET /api/collections/exam/{examId}`：独立大纲及答案状态；每个响应附公共 exam 元数据与服务器时间。
- `GET/POST .../exam`：查询／交卷。交卷幂等；已锁定考试只能重试固定答案的评分。
- `DELETE /api/collections/exam/{examId}/exam`：取消并删除未完成考试或待处理评分；返回 `{deleted:examId}`，重复删除幂等。已完成考试返回 `409 EXAM_COMPLETED`，应使用原题库历史删除接口；已删除考试的读取、交卷和保存返回 404。校验写请求来源；历史关闭时只能删除原页面会话的考试。重放已删除考试的开始请求返回 `409 EXAM_DELETED`，新的开始请求创建新考试。
- `GET .../questions/{qid}/page`：使用本次考试冻结的页面。既有 questions、actions、AI、history 路由受考试状态守卫。
- `GET .../resources/{sha256}`、`POST .../resources`：考试图片读取及作答图片上传；临时考试图片仅驻内存，交卷后禁止上传。

考试进行中禁止 summary/editor/edit/submit/retry/review/AI 写请求；可保存 draft 和 whiteboard。交卷后答案与白板锁定，评分中可用人工 review 和 AI 请求，完成后全部只读。计时页面按服务器时间显示，后台每秒检查到期；每次请求也先检查截止时间，无法通过刷新或延后请求延长考试。
