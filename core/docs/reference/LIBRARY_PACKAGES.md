# 物理目录与独立副本导入

## 名称与目录

题库分组、单个题库、拓展分组和单个拓展均对应物理文件夹，界面名称直接取文件夹名。旧独立 JSON 文件仅显示升级错误，不能继续作为当前题库打开。普通题库内容编辑不修改该目录名称。

~~~text
question-banks/
  考研英语/
    1997年真题/
      bank.json
      assets/
extensions/
  考研英语/
    完形填空/
      manifest.json
      practice.html
      rules.js
      ...
~~~

题库和拓展都只支持一层分组。新建题库分组直接创建物理文件夹。应用内题库改名、移动落实到磁盘，并保留本地作答身份。拓展及其分组禁止通过管理界面改名、移动、编辑代码；有题库引用时禁止删除，未引用的实体或分组可移入回收目录。体验样例及受控题目内容编辑继续提供。

不再使用逻辑拓展分组和显示名称覆盖表；旧 .state/extension-groups.json、library-labels.json 保留在磁盘但不参与新目录展示，也不自动搬动已有代码。

## 拓展引用

新题库使用准确的数据根目录相对路径：

~~~json
"extension":{"path":"extensions/考研英语/完形填空"}
~~~

根默认绑定与逐题覆盖都支持该写法。单套包可以包含多个拓展，每题须通过有效默认或覆盖绑定指向具体拓展目录。题库移动不改变该路径；外部移动、改名拓展时应恢复原路径或由制作者修正引用。缺失时明确报错，不自动寻找或切换到另一个同名拓展。

当前题库与拓展样例均须使用准确的 {path} 绑定；可选 id 仍核对所属拓展。旧 {id,version}、development 绑定返回 422 EXTENSION_REFERENCE_UPGRADE_REQUIRED；根平铺拓展和旧独立 JSON 返回对应目录升级错误。包内样例必须准确自引用所属拓展，不自动按 ID、版本或叶名猜测。

## 包格式 3

支持整组和单题库两种 .qbank 导出，文件名分别为 <题库分组名>.qbank、<题库名>.qbank。外部是一个 ZIP 容器，内部同时携带所选题库和配套拓展：

~~~text
quizforge-package.json
question-banks/<组名>/<题库名>/bank.json
question-banks/<组名>/<题库名>/assets/
extensions/<组名>/<拓展名>/manifest.json
extensions/<组名>/<拓展名>/...
~~~

整组清单为：

~~~json
{"format":"quizforge-bank-group","formatVersion":3,"group":"考研英语"}
~~~

单题库清单在相同格式上增加 `"scope":"bank"`，`group` 使用导出题库的文件夹名。包内仍有一层暂存分组，但恰好只有一本题库；导入后该题库直接放到 `question-banks/<题库名>/bank.json`，配套拓展放到 `extensions/<独立拓展组>/<拓展>/`。只携带此题库实际使用的拓展及资源，不携带原分组的其他题库。省略 scope 或 scope 为 group 时按分组导入，即使组内只有一本；其他 scope 拒绝导入。

不携带分组 UUID、拓展去重哈希清单或本地保存身份。题库/拓展旧 id、version 可保留为元数据，不比较版本、不要求 UUID 或全局唯一。新包导入时可补齐缺省题库 id/title、拓展 id/version/name；题目/小题 ID 仍须稳定且在所属范围内唯一。API/SDK 版本声明仍按原协议验证。

导出按实际引用收集全部拓展及资源；不同来源的同名拓展在包内分配独立名称并同步路径，不按内容去重。只在导出暂存副本修改引用和名称，不改变本地题库或拓展。导出源也须先完成物理目录和路径绑定升级。

## 导入流程

1. 只接受格式 3。旧包格式 1、2 返回 422 UNSUPPORTED_LIBRARY_ARCHIVE，说明需要制作者升级题库包；不运行旧导入、覆盖或去重分支。
2. 隔离暂存，校验格式、目录深度、声明、文件大小、解压路径、题目/样例规则及资源完整性。格式 3 必须使用精确拓展路径且引用包内实体。
3. 使用上传 .qbank 文件基名作为新分组名（整组包）或根目录题库名（单题库包）；无文件名的内部调用使用清单组名。处理非法文件名；题库根目录和拓展根目录分别避让现有文件或目录，重名加（2）、（3）等序号，不假设两边序号相同。单题库的 title 同步最终文件夹名。
4. 每次均安装全新副本，即使内容完全相同也不跳过、合并、复用或替换。题库与拓展目录整体安装，失败回滚本次两组目录。
5. 只重写本次新题库的根默认及逐题绑定，使其指向实际安装的拓展目录。已有题库和拓展不修改。
6. 为新副本分配独立本地保存身份。作答、草稿、考试及历史不与旧副本共享，新版题库也不自动继承旧进度。

导入校验保留同一物理拓展的批量规则校验与两进程上限，正常保存、切题不增加全目录去重检查。

## 删除与配套拓展

删除题库分组或单题库时，从被删除题库的默认及逐题绑定收集实际引用的物理拓展组；不按名称推断配套关系，题库改名、移动后仍适用。若其他现存题库仍引用组内任意拓展，整组保留。其他题库无法读取或引用无法确认时，同样保留候选组并提示，不阻止删除题库。未被其他题库使用的配套拓展组与题库一起移到同一个 `.trash/library/<回收编号>/`，不永久删除。

回收目录的 `content/` 保存题库，`extensions/` 保存本次一并删除的拓展组，`receipt.json` 记录原路径、回收路径和操作状态。普通移动失败时回滚已移动项目；若回滚也失败，报告需要恢复的回收目录。作答和冻结历史文件保持原样。此清理只在用户确认删除时执行，不做启动扫描去重或清理全部未引用拓展。

## 本地保存身份与兼容

新导入题库内部由宿主写 .instance.json（schemaVersion:1、随机本地 id），集合路由为 g.<本地实例id>，保存键为 bank:<路由id>:mixed。该身份仅用于隔离进度，不用于导入比较；不会出现在导出包中，不接受包内携带的此文件。

新导入拓展组有宿主生成的 .bundle.json，用于确保导入副本按实际路径分配拓展预览路由。该文件同样不导出、不接受包内携带。题库和拓展的名称始终来自文件夹；内部标识不替代名称。

当前目录只加载已升级的题库文件夹、物理拓展分组和准确路径绑定；旧入口返回升级提示，不自动搬动或改写个人文件。内部题库保存身份、应用内改名/移动的记录关联、已保存状态恢复及冻结历史解码继续保留。冻结历史使用原快照，不重映射、不重算。不承诺资源管理器手动复制或移动后自动识别原练习实例。

内容版本、资源哈希、缓存及 AI 过期保护仍保留；取消的是导入去重/替换，不是这些内部一致性机制。

## 限制

包不含作答、草稿、历史、设置或密钥。上传 64 MiB、解压 128 MiB、单文件 8 MiB、10000 个条目；资源图片保留 SHA-256 和 4 MiB 检查。普通 ZIP 改后缀不能替代完整格式。取消操作或错误会清理暂存，不能只安装半套内容。
